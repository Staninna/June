# Local LLM API

June's Local AI talks to the SmolChat Server fork on this phone. The contract (endpoints,
pairing, waking the server, errors, privacy) lives in one place, the SmolChat repository:

https://github.com/Staninna/SmolChatServer/blob/my-main/docs/LOCAL_LLM_API.md

Section numbers in June's code (for example §3.5) refer to that file. June follows contract v3.
